# Security Policy

MiniMesh is a learning and demonstration project. It is not production-ready
service-mesh software.

## Supported versions

Security fixes are made on the default branch only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private security advisory for this repository when available, or contact the
maintainer through the GitHub profile linked to the repository. Include a
minimal reproduction, affected component, impact, and any suggested mitigation.

Do not include credentials, private keys, certificates, or other secrets in a
report.
